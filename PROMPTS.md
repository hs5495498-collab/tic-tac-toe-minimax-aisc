# Prompt Sequence Used to Build the Minimax and Alpha-Beta Pruning Visualizer

### 
"Implement Minimax and Alpha-Beta Pruning in Python using the same game tree. Keep the algorithms recursive, alternate between MAX and MIN nodes, and include trace output and node counting in `minimax.py`."

### 
"Create a Flask backend around my existing Python code. Add API endpoints to return the game tree and execute either algorithm, returning the result, visited-node count, and execution events as JSON."

###  
"Build a simple frontend using HTML, CSS, and vanilla JavaScript. Use `fetch()` to call the Flask API and display the actual events generated by the Python algorithms instead of reimplementing the logic in JavaScript."

### 
"Create an interactive game-tree visualization with buttons for Minimax, Alpha-Beta, step-by-step execution, play/pause, speed control, and reset. Highlight visited nodes and use different styling for pruned branches. Also display alpha, beta, node counts, and the final result."

### 
"Add pytest tests for the algorithms and Flask endpoints. Verify that both algorithms return 5, Minimax visits 15 nodes, and Alpha-Beta visits 11 nodes. Check the pruning events, fix frontend issues such as stale animation state or overlapping requests, and test the complete application locally."
